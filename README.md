## 🤔 Что это

Небольшой квиз для заучивания дат по истории (или чему угодно, где есть «дата — событие»).

Загружаешь текстовый файл формата:

```text
	1917--Февральская революция
	1945--Победа в Великой Отечественной войне
```

→ программа показывает дату и 4 варианта события → угадываешь → получаешь оценку 📊

## ⚙️ Как работает

1. 📂 Парсим `.txt` файл: строка режется по `--`, собираем `Map<дата, события>`
2. 🎲 Случайно выбираем дату, ставим верный ответ в случайную из 4 радиобатоннов
3. 🃏 Остальные 3 варианта — случайные события из того же файла
4. ✅/❌ Проверка ответа, счётчик попаданий
5. 🏁 В конце — итоговая оценка по пятибалльной шкале (см. ниже)

### Шкала оценок

| Процент верных | Оценка            |
| -------------- | ----------------- |
| 100%           | 5                 |
| 95–99%         | 5−                |
| 80–94%         | 4                 |
| 75–79%         | 4−                |
| 55–74%         | 3                 |
| 53–54%         | 3−                |
| 1–52%          | 2                 |
| 0%             | **Dima Ignashev** |

_(последний пункт — внутренняя шутка, не спрашивайте)_

## ✨ Топовейшие Фичи

- Окно без рамки, перетаскивается за верхнюю панель
- Рандомная расстановка верного ответа - запомнить позицию не выйдет
- Подсчёт счёта в реальном времени
- PopUp с итоговой оценкой
